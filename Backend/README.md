# Getting Started
## Packages
You will need to install the following packages:
- Java ≤ 17
- Springboot ≤ 3.5.7 
- maven ≤ 4.0
- RabbitMQ ≤ 4.1
- MySQL ≤ 9.5.0
- Docker ≤ 4.49.0

### RabbitMQ
started automatically using Docker.

### MySQL
started automatically using Docker.
